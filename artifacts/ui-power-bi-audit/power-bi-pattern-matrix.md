# Power BI Pattern Matrix

Official Microsoft references accessed 2026-08-03: Power BI reports overview, dashboard design tips, filters/highlighting, slicers, drillthrough, drill mode, bookmarks, focus mode/accessibility, filter pane, and consumer filtering docs from Microsoft Learn.

| Pattern                | Power BI behavior                                                                   | Kondisi existing                                                                                              | Cocok untuk PT AMA?                               | Rekomendasi                                                                                                            | Priority |

| report canvas          | Multi-page interactive report with arranged visuals and clear hierarchy.            | `/dashboard` and `/finance/dashboard` use KPI/chart/table panels, but hierarchy and context are inconsistent. | Yes for management/reporting pages only.          | Create `ReportPageShell` with page title, context, common slicers, KPI row, visual grid, exception list, source/as-of. | P1       |
| KPI card               | Metric label, value, trend/comparison; should support context.                      | Finance KPI has comparison; generic `DsStatCard` only label/value/tone.                                       | Yes.                                              | KPI v2 must include period, unit, comparison, target, variance, trend, source, last updated, definition.               | P1       |
| slicer                 | Visible canvas filter for common filters.                                           | Date/station/type/status filters exist on dashboard, flight list, flight following.                           | Yes.                                              | Keep common slicers visible; add active chips, reset, count, and scope label.                                          | P1       |
| filter pane            | Central filters by visual/page/report/drillthrough; can be formatted/hidden/locked. | No report-level filter drawer pattern.                                                                        | Yes, but not permanent on operational pages.      | Use right drawer for advanced report filters only; collapsed by default on operational workspace.                      | P2       |
| cross-filter           | Selecting a visual filters related visuals.                                         | Not implemented in observed charts.                                                                           | Selectively.                                      | Use only analytical pages; never trigger operational state mutation.                                                   | P2       |
| cross-highlight        | Related data highlighted, unrelated data dimmed.                                    | Not implemented.                                                                                              | Yes for charts where comparison context matters.  | Use highlight for status/category exploration; distinguish from actual filter chips.                                   | P2       |
| drill-down             | Move through hierarchy in same visual.                                              | No standard chart hierarchy controls.                                                                         | Yes for finance, fleet, station, MRO trends.      | Start with Year > Month > Day, Fleet > Type > Aircraft, Account Group > Account.                                       | P2       |
| drill-through          | Navigate to detailed page filtered to selected context.                             | Links to detail exist, but context/back state not standardized.                                               | Strong yes.                                       | Query context contract: source route, filters, selected entity, return label.                                          | P1       |
| focus mode             | Visual expands for inspection.                                                      | No visual focus action.                                                                                       | Yes for charts, map, dense tables.                | Add hover/overflow visual header action "Open focus".                                                                  | P3       |
| show data              | Data behind visual available as accessible table.                                   | Some charts have separate lists; no visual-level show-data standard.                                          | Yes.                                              | Add show-data drawer/table for analytical visuals.                                                                     | P2       |
| visual header          | Hover/context actions: focus, filters, export, more options.                        | Refresh exists at page/panel level; visual actions inconsistent.                                              | Yes.                                              | Standardize lightweight visual header with more menu.                                                                  | P2       |
| page navigator         | Consumer navigates report pages/tabs.                                               | `VTabs` used in dashboard/accounting; sidebar used globally.                                                  | Yes for report groups.                            | Use report-local tabs: Summary, Trend, Exceptions, Detail.                                                             | P2       |
| bookmark               | Captures page/filter/slicer/visual state.                                           | No saved/bookmark view contract found.                                                                        | Later.                                            | Start with URL shareable filters; then personal saved views.                                                           | P3       |
| saved view             | Persistent personal/shared preset.                                                  | Not present.                                                                                                  | Yes after filter framework.                       | Save filters, period, sorting, visible columns, page; never save permissions.                                          | P3       |
| matrix                 | Hierarchical rows/columns, subtotal/grand total.                                    | Tables exist; no analytical matrix component.                                                                 | Yes for finance/accounting and cost reports.      | Introduce MatrixTable for trial balance, HPP, route cost, ledger summaries.                                            | P2       |
| export                 | Export data/report.                                                                 | Inventory CSV endpoint exists; visual/page export not standardized.                                           | Yes with permission and source-state constraints. | Report export should include filters, source, generated-at, role.                                                      | P2       |
| refresh state          | User can refresh and see current data.                                              | Refresh buttons exist; pending shown, but stale/current semantics inconsistent.                               | Yes.                                              | Standard `DataFreshnessBadge`: live/near-real-time/snapshot/historical/stale.                                          | P1       |
| last updated           | Reports show data refresh timestamp.                                                | Finance shows `As of`; MRO stale uses `generatedAt`; dashboard lacks consistent as-of.                        | Yes.                                              | Every report page must show period, timezone, source, last updated.                                                    | P1       |
| metric definition      | Explain what KPI means.                                                             | Not standard.                                                                                                 | Yes.                                              | Tooltip or definition drawer per KPI/visual.                                                                           | P1       |
| responsive report view | Power BI supports mobile-optimized report layouts.                                  | Mobile screenshots show clipped content.                                                                      | Required.                                         | Define mobile report layout separately: top slicers, stacked cards, single-column visuals, no horizontal clipping.     | P0       |
