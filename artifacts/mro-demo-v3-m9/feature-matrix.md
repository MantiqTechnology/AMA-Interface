# PT AMA MRO Demo-v3 — Feature Matrix

## DEMO VERIFIED

- Resource readiness: Material, Personnel, Tools
- Material reservation, issue, install, traceability, and concurrency
- Defect report, assessment, NO-GO, deferred restriction, expired deferment block
- Non-routine finding, corrective Job Card, rework, reinspection
- Maintenance Due Control, WP creation from due, release-linked compliance, next due recurrence
- Facility hierarchy: Station -> Facility -> Area/Hangar -> Bay
- Maintenance Slot booking, reschedule/cancel, planned conflict protection, occupancy timeline
- Personnel eligibility, assignment, confirmation, release, schedule conflict
- Tool eligibility, calibration enforcement, allocation, custody, return, conflict
- GSE master via managed assets, requirement, allocation, staging, conflict
- Facility readiness evaluator
- Actual aircraft movement/custody, bay actual occupancy, move-out, handback
- Shift handover prepare/acknowledge as operational context, not sign-off
- Technical Record package and unified release eligibility
- Technical Release and immutable release evidence snapshot
- Aircraft technical eligibility consumed by Flight readiness
- Flight Release and Departure backend revalidation
- Maintenance operational availability distinct from technical eligibility
- Browser acceptance evidence and M1-M8.5 regression matrix

## DEMO PARTIAL

- Approved maintenance data is recorded as reference evidence, not a full revision-controlled document management system.
- Flight readiness is sufficient for Demo-v3 gates, not a complete airline dispatch compliance engine.
- Facility manpower capacity is eligibility/assignment based, not full roster optimization or fatigue management.
- GSE control covers operational allocation/staging, not full GSE maintenance or procurement.
- Calibration enforcement exists for tools where modeled, not a full metrology laboratory workflow.
